# 📜 服务端 RESTful CRUD 语义与状态码标准规范
> **适用范围**: 微服务 / 后端业务 API

---

## 1. 核心 HTTP 动词语义
- **`GET`**: 严格只读且幂等，严禁在 GET 请求中执行状态修改或数据写入；
- **`POST`**: 资源创建或执行触发特定业务动作；
- **`PUT`**: 资源的完整覆盖更新；
- **`PATCH`**: 资源的局部差异字段更新；
- **`DELETE`**: 资源的逻辑删除或物理删除。

---

## 2. 状态码规范
- **`200 OK`**: 请求处理成功并返回数据；
- **`400 Bad Request`**: 客户端入参 DTO 校验失败；
- **`401 Unauthorized`**: Token 缺失或已过期失效；
- **`403 Forbidden`**: 权限不足，被 RBAC 守卫拦截；
- **`500 Internal Server Error`**: 服务端未捕获的严重内部异常。
